# Бюджет-бот: Ozon Банк → Google Таблица → Telegram

Телефон пересылает уведомления Ozon Банка в Google Таблицу. Скрипт сам считает бюджет и пишет в Telegram:

- **1-го числа** — итоги прошлого месяца и план на новый: сколько откладывать, сколько можно тратить в день и в неделю.
- **По понедельникам** — куда ушли деньги за неделю, идёшь ли по плану, лимит на день до конца месяца.
- **Каждый вечер в 21:00** — сколько потрачено сегодня и сколько можно завтра.

Твои траты хранятся только в твоей Google Таблице. В этом репозитории лежит только код, без твоих данных.

---

## Шаг 1. Бот в Telegram (2 минуты)

1. Открой в Telegram **@BotFather** и нажми «Start».
2. Отправь ему `/newbot`, потом любое имя (например «Мой бюджет»), потом логин, который заканчивается на `bot` (например `rodion_budget_bot`).
3. BotFather пришлёт **токен**, длинную строку вида `123456789:AAH...`. Скопируй её и никому не показывай.
4. Открой своего нового бота по ссылке из сообщения BotFather и нажми **«Start»**.

## Шаг 2. Google Таблица и скрипт (5 минут)

1. Открой **https://script.google.com** и нажми **«Новый проект»** (или «Создать проект»).
   С телефона: в Chrome нажми ⋮ → **«Версия для ПК»**, иначе редактор не откроется. С компьютера удобнее.
2. Удали всё в редакторе.
3. Вставь целиком код из файла [`Code.gs`](Code.gs). Таблица «Бюджет» создастся сама при первом запуске `setup`, ссылка на неё появится в журнале.
4. В начале кода, в блоке `CONFIG`, поправь свои цифры: доход, сколько нужно на жизнь, обязательные платежи.
5. Нажми 💾 (Сохранить).
6. Слева **⚙️ Настройки проекта**:
   - **Часовой пояс** — `(GMT+03:00) Москва`;
   - внизу **Свойства скрипта → Добавить свойство**: название `TELEGRAM_TOKEN`, значение — токен из шага 1. Сохрани.
7. Вернись в редактор (слева `< >`). Вверху выбери функцию **`setup`** и нажми **▶ Выполнить**.
   Google попросит разрешения: «Проверить разрешения» → свой аккаунт → «Дополнительно» → «Перейти к проекту» → «Разрешить».
   Внизу в журнале появится **секретный ключ**. Скопируй его.
8. Выбери функцию **`connectTelegram`** → **▶ Выполнить**. В Telegram придёт «✅ Бот подключён!».
9. Вверху справа **Начать развертывание → Новое развертывание**:
   - тип (⚙️) — **Веб-приложение**;
   - «Запуск от имени» — **Я**;
   - «У кого есть доступ» — **Все**;
   - **Начать развертывание** → скопируй **URL веб-приложения** (`https://script.google.com/macros/s/.../exec`).

> «У кого есть доступ: Все» нужно, чтобы телефон мог присылать данные. Без секретного ключа скрипт ничего не принимает, а читать таблицу через этот адрес нельзя.

## Шаг 3. MacroDroid на телефоне (5 минут)

1. Установи **MacroDroid** из Google Play.
2. **Добавить макрос**:
   - **Триггер:** Уведомление → **Уведомление получено** → приложение **Ozon Банк** (если банк внутри приложения Ozon — выбери Ozon). Текст — «Любой».
   - **Действие:** Подключение (Web) → **HTTP-запрос**:
     - метод **POST**;
     - URL — адрес из шага 2.9;
     - вкладка **Параметры запроса** (Query parameters), добавь два:
       - `key` = секретный ключ из шага 2.7;
       - `text` = через кнопку «…» вставь **Текст уведомления** (`[notification]`).
3. Сохрани макрос. MacroDroid попросит доступ к уведомлениям — разреши.
4. **Важно для Xiaomi/Redmi/POCO:** Настройки → Приложения → MacroDroid →
   **Автозапуск — вкл**, **Контроль активности / Батарея — «Нет ограничений»**. Иначе телефон будет усыплять MacroDroid.

## Шаг 4. Проверка

Купи что-нибудь по карте Ozon Банка или переведи себе немного денег с другого банка. Через несколько секунд в таблице на листе **«Операции»** появится строка. Чтобы сразу получить отчёт, в Apps Script выбери `dailyReport` и нажми ▶.

Переводы между своими счетами в Ozon (например, в копилку и обратно) бот не считает ни доходом, ни тратой.

---

## Как бот считает

- План строится **по худшему месяцу**: доход минус разброс (10 000 − 3 000 = 7 000 ₽).
- С этих денег оплачиваются обязательные платежи и «на жизнь», остальное — **копилка**. Бот пишет, какой процент откладывать с каждого поступления.
- Всё, что пришло **сверх минимума**, — целиком в копилку.
- Лимит на день пересчитывается каждый день: потратил больше — завтра можно меньше, сэкономил — больше.

## Если что-то не работает

- **В таблицу ничего не приходит** — открой URL веб-приложения в браузере: должно быть «Бюджет-бот работает». Проверь ключ в MacroDroid и что у MacroDroid есть доступ к уведомлениям.
- **Поменял код** — сохрани и сделай «Начать развертывание → Управление развертываниями → ✏️ → Версия: новая → Развернуть», иначе работает старая версия. После правки `CONFIG` запусти `setup` ещё раз.
- **Трата попала не в ту категорию** — исправь ячейку «Категория» в таблице вручную или добавь слово в список `CATEGORIES` в коде.
